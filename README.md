# GM3323D 与蓝牙耳机电量查看器

基于 [yszyszysz233/2.4G-battery-viewer](https://github.com/yszyszysz233/2.4G-battery-viewer)
制作的 **GM3323D 与蓝牙耳机分支**。简洁面板与托盘显示鼠标和选中的蓝牙耳机；
原项目的 ATK / DARKRIM 等调试读取代码保留在 `app.py` / `battery.py` 中。

已在真实 GM3323D 接收器（`1D57:FA60`）上读到 **80%**。
鼠标按 **10% 一档**上报，不是逐 1% 的精确测量。
鼠标只监听电量报文，不修改 DPI、灯效、宏或固件。运行无需安装厂商软件。

支持 **EDIFIER W820NB 双金标版**，每次刷新发送固定的电量查询指令，校验耳机回复。
实机直接读到 **94%**，而同一时刻 Windows 的电量属性仍为 **100%**。
因此这款耳机不再把 Windows 属性当作实时电量，直查失败会显示未知。

## 使用

需要 Windows 10/11、Python 3.10+（包含 tkinter）；无需安装第三方 Python 包。

1. 下载本分支的全部文件并解压到固定文件夹。
2. 插入 GM3323D 的 USB 接收器，打开鼠标并移动一下。
3. 双击 `GM3323D.bat` 打开面板。
4. 启动后自动显示右下角鼠标与耳机两个电量圆环；悬停查看整数百分比，点击“收起”隐藏面板。
5. 在“设置 → 蓝牙耳机”选择 EDIFIER W820NB 双金标版；也可自动选择已连接耳机。

也可以在项目文件夹打开终端运行：

```bat
python my_devices.py
```

只读一次：

```bat
python my_devices.py --once
```

若系统使用 Python Launcher，可将 `python` 换成 `py -3`。

## 托盘与设置

- 左键托盘图标：刷新电量；右键：打开面板。
- 右上角可选 **石墨黑、云雾白、午夜蓝、森林绿** 四套皮肤；即时生效并保存，托盘配色同步。
- 启动面板会自动启动托盘，无需额外点击。Windows 可能将新托盘图标放进右下角的 `^` 折叠区，可拖到常显区域。
- 窗口和任务栏使用独立的电池应用图标，不再显示 Python 默认图标。
- 默认使用圆环进度图标，中心图案区分鼠标与耳机；“设置 → 托盘图标”可切换为数字百分比。
- 面板直接显示整数百分比，不按十位取整。耳机保留 `94%` 等原始读数；GM3323D 接收器目前只上报 10% 档位，无法提供实测的 `81%`、`82%`，不会估算填充。
- “设置 → 蓝牙耳机”支持指定耳机、自动选择已连接耳机、显示全部已配对耳机。
- 默认每 60 秒刷新，设置中可调整为 30 秒至 30 分钟，也可暂停自动刷新；升级保留原刷新间隔。
- “立即刷新”或 F5 可手动读取；Ctrl+, 打开设置。查询在后台执行，界面保持响应。
- 点击“收起”启动托盘并隐藏面板；托盘已运行时关闭面板会隐藏，点击“退出”结束面板与托盘。
- 开机自启默认关闭；需要时在设置勾选，启动项名称为“GM3323D 电量托盘”。
- “设置 → 桌面入口”会创建项目目录与两个启动入口的链接。
- 主动修改设置时保存 `tray_config.json`；不保存电量历史，不写电量日志。
- 开机自启与桌面入口依赖项目目录，请先把项目放到固定位置。

直接启动或退出托盘：

```bat
pythonw tray_app.py
python tray_app.py --quit
```

## 读不到时

- 显示找不到接收器：重新插拔 USB 接收器，确认是 GM3323D、`1D57:FA60`。
- 显示超时或未连接：打开鼠标，移动唤醒，再点击刷新；鼠标最多等 5 秒，耳机直查最多等 3 秒。
  如果面板与托盘同时刷新，耳机查询可能额外排队最多 3 秒；失败时可点击刷新重试。
- 无数据时面板显示 `—`，不会把旧数据或不认识的字节当成当前电量。
- 当前只验证 2.4G 连接下的电量；有线电量和独立充电状态尚未实机验证。
- 不保证其他型号、相同芯片或不同接收器版本兼容。
- 蓝牙耳机必须已与本机配对并连接。已验证的 EDIFIER 型号使用专用 RFCOMM 电量查询；只发送电量 GET，不修改设置。
- EDIFIER 直查失败不会退回显示 Windows 的满电值。其他未适配耳机仍显示“系统参考值”，更新时间无法确认。
- 不会触发扫描、重新配对或切换音频模式；同一耳机的面板和托盘查询会串行执行，避免占用冲突。
- 耳机关机或断开后，下次刷新显示未连接；连接检查失败时显示未知。
